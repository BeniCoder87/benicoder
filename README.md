# Callofyar Bot - سایت فروش سورس ربات سی‌پی

یه صفحه وب ساده و جذاب برای فروش سورس ربات تلگرامی سی‌پی کالاف دیوتی.

## ویژگی‌ها
- طراحی ریسپانسیو برای موبایل و دسکتاپ
- گرادینت و افکت‌های بصری
- لینک دانلود و خرید
- فونت فارسی وزیری

## تکنولوژی‌ها
- HTML5
- CSS3
- Google Fonts

## اجرا
فایل `index.html` رو تو مرورگر باز کنید.
